# terrain

**Owner:** Ramish (terrain and map data track, commits tagged [P2])

**What goes here:** Elevation, slope, roughness and other map layers on the shared 2 m grid: grid.json, .bin layers, PNG previews, terrain.meta.json. GeoTIFF masters stay in terrain/out/ only if under 50 MB; bigger ones go to the shared drive.

Only the owner pushes to this folder. Need a change? Ask the owner in the group.
